| `RUN_COUNT` | Number of sorted class runs in the tables below. |
| `WHITESPACE_COUNT` | Number of code points the patterns treat as whitespace. |
| `RUN_STARTS` | First code point of each run, six hex digits each. |
| `RUN_ENDS` | Last code point of each run, six hex digits each. |
| `RUN_CLASSES` | Class of each run, one hex digit each. |
| `ASCII_CLASSES` | Class of each of the 128 ASCII code points, one hex digit each. |
| `WHITESPACE_CODE_POINTS` | Whitespace code points, six hex digits each. |

| Function | Description |
| --- | --- |
| `def class_of_code_point(code_point: Int) -> UInt8` | Return the Knap class of one code point. |
| `def is_letter(code_point: Int) -> Bool` | Report whether a code point is in Unicode category L. |
| `def is_number(code_point: Int) -> Bool` | Report whether a code point is in Unicode category N. |
| `def is_mark(code_point: Int) -> Bool` | Report whether a code point is in Unicode category M. |
| `def is_whitespace(code_point: Int) -> Bool` | Report whether a code point is whitespace for these patterns. |

### `utf8`

UTF-8 decoding for the Knap pre-tokenizer.

#### `CodePointRead`

The result of decoding one UTF-8 sequence.

| Field | Type | Description |
| --- | --- | --- |
| `code_point` | `Int` | The decoded code point, or the raw byte value when malformed. |
| `width` | `Int` | Bytes consumed. Always at least one, so scanning terminates. |
| `valid` | `Bool` | False when the bytes were not a well formed UTF-8 sequence. |

| Function | Description |
| --- | --- |
| `def decode_at(data: Span[UInt8], index: Int) -> CodePointRead` | Decode the UTF-8 sequence starting at one byte offset. |
| `def is_lead_byte(byte: UInt8) -> Bool` | Report whether a byte may begin a UTF-8 sequence. |
